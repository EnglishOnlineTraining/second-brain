# Second Brain — Project Instructions

This directory is a **Logseq graph** (`journals/`, `pages/`, `logseq/config.edn`,
`assets/`) doubling as a personal knowledge-management vault (learning science +
AI-optimized activities research), separate from any other project on this
machine. **Read `CLAUDE_CODE_INSTRUCTIONS.md` in full before any operation
here** — it defines the five automations (`/ingest`, `/write`, `/manage`,
`/review`, `/maintain`), Logseq's page/property/block conventions, and
namespace rules.

Also read `pages/mem-claude.md` for identity, focus areas, preferences, and
goals, and check `log.md` (top entries) plus the most recent `journals/*.md`
for recent activity before starting new work.

Open this folder directly as a graph in the Logseq app (Add graph → this
folder) to browse/edit it visually; Claude Code and Logseq read and write the
exact same files.

These instructions apply **only within this `second-brain/` directory** —
they do not extend to any other project or repository.
