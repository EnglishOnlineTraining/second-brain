- > Evolving record of how the system should work. Update as you learn what works. Mirrors [[mem/claude]] §4 — that page is the canonical copy; this one exists so preference changes can be tracked/linked on their own.
- ## Writing
	- Prefer concise (300-600 words per wiki page)
	- Prefer specific claims with evidence
	- Prefer actionable over theoretical
	- Use active voice
	- Mark strong opinions as such
- ## Linking
	- Every new page needs ≥2 outgoing `[[references]]`
	- Aim for ≥1 incoming reference within 48 hours
	- Use `#tags` sparingly (`#spaced-repetition`, `#adaptive-learning`)
	- Prefer `[[page references]]` over bare URLs in block text
- ## Output
	- Reports: TL;DR first, scannable, referenced
	- Presentations: story-driven, one idea per section, visual placeholders
	- Templates: reusable, with variables, examples, and usage instructions
	- Documents: formal, versioned, with approval workflow
	- Visuals: diagrams over paragraphs
- ## Ingestion
	- Read sources completely before extracting
	- Rate evidence quality (strong/moderate/weak/anecdotal)
	- Create permanent notes for original insights
	- Cross-link aggressively
- ## Review
	- Weekly review every Sunday
	- Monthly review first of month
	- Update [[mem/claude]] if system changes
